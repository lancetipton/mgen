## Description

Here is a markdown comment describing the functionality and logic of the "/dqmc_flag_updates.py" module:

DQMC Flag Update Module

This module is responsible for updating the 4 flags (DMI, registration, consumer, DMI_commercial) on IMD and match candidates records where the flags may have changed due to data updates.

The flags are used for ordering matches and determining which records can be pulled from DMI or DMI_Commercial. This process ensures the flags stay in sync with the latest data.

It works by:

1. Dividing the processing across multiple processes in parallel to speed up the updates.

2. Finding insertions and deletions of relationships between IMD and match candidates since the last run.

3. Loading these changes into staging tables on IMD.

4. Updating the relevant flags on IMD and match candidates based on the new relationships.

5. Transferring the flag updates to match candidates tables.

6. Indexing the tables to optimize future lookups and flag updates.

It handles various entity types (name/address, name/phone, name/email) and data sources (DMI, registration, consumer, DMI_commercial). Compliance rules are also checked before updating DMI_commercial flags.

The process is monitored to avoid conflicts with concurrent data loads. On success/failure it updates a semaphore and sends notifications.

This ensures the critical DQMC flags stay in sync as the underlying data changes, enabling downstream processes to have accurate information.

  	def dqmc_semaphore_running(self):
  		"""
  		Checks if any dqmc ingestion is currently running. We don't want to update records at the same time with an active dqmc a/p/e semaphore ingestion.
  		"""
  		try:
  			done = False 
  			conn = Connection('IMD').get_connection()
  			while not done:
  				sql = self.dqmc_sql["check_semaphore_running"]
  				with conn.cursor() as cur:
  					cur.execute(sql)
  					count = cur.fetchone()[0]
  				if count > 0:
  					time.sleep(60)
  					logging.info('Semaphore is still running. Sleeping for 60 seconds ')
  				else:
  					done = True
  
  		except Exception as e:
  			logging.exception(e)
  			raise e 
  		finally:
  			conn.close()
