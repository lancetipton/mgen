## Description

Event ETL Module

This module defines the EventETL class which handles the Extract, Transform, Load (ETL) process for event data from various sources into the IMD (I360 Master Data) data warehouse.

The class takes in a partition and content type as parameters. It then has methods for checking if there are records to process, setting a flag for the first load, truncating and loading data into staging tables, writing files, setting file record counts, transferring file content to Kafka, loading to S3, transferring to Kafka queues, logging events, tracking instances, deleting processed records, vacuuming and analyzing tables, and sending failure emails.

The methods interact with the IMD database using SQL queries defined in the 'sql' dictionary to extract, transform and load data between staging tables and various target systems. Utility classes like Connection, QueryExecutor, DFT and Mailer are used to interface with the database, execute queries, run data flows and send emails.

The overall flow is to first check for and prepare data, then extract it from sources into staging tables. The data is then transformed and loaded out to various targets like files, Kafka, S3, downstream databases and queues using different methods before cleaning up by deleting records and optimizing tables. Failure handling includes logging and email notifications.
