## Description

DQMCINAddressFull Module

This module handles the full data quality match candidate (DQMC) ingestion process for individual name and address data.

It takes raw individual, address, and registration data from a source database, performs data quality checks and matching, and loads the cleaned/matched data into staging and final tables in both the IMD and MC databases.

The main steps are:

1. Create necessary tables in IMD and MC databases

2. Load distinct INPKs and ALPKs from source

3. Get individual, address, and registration data from source

4. Perform address geocoding and splitting

5. Build staging table by joining all data

6. Deduplicate staging table

7. Load deduped data into final tables in IMD and MC

8. Create indexes on final tables

9. Update IMD and MC tables for each state

It utilizes various utility classes like QueryExecutor, PGDatabaseReader/Writer, and DFT to orchestrate the ETL process. The source SQL, columns, and states are configured via files. Overall it implements the full DQMC pipeline to ingest, clean, match, and load individual name and address data from a source into IMD and MC databases.
