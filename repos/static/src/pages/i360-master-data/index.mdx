
# I360 Master Data (IMD)

> The ingestion and dissemination of core business objects for our organization and clients.

IMD refers to both the ingestion engine and data storage of master data for I360. The domain is individual-centric, as I360's core capability is providing clients with data about individuals . Data relating to individuals can include:

- Attributes about the individuals themselves (Name, Gender, DOB, Race)

- Contact Information (Addresses, Phones, Emails)

- Voter Data (Registration records, Vote History, Political Geography)

- Consumer Data (Income, Education, Lifestyle, Behavior, Housing)

- Model Scores

- Taxonomies (survey data, defined universes)

This list is not exhaustive, and can be expanded to relate to other entity types relating to individuals, or other domains, as required by business needs.

The ingestion engine accepts requests to ingest files (provided lists) from a number of sources. Requests to ingest a provided list are mapped to resources of the ingestion engine to run, the specific instances of which are called semaphore requests. Resources are the runnable code for coordinating data ingestion into an entity type table object (e.g. con.email), or a handling a part of the data ingestion (e.g. Address - DQ Match). A file will be ingested as resource dependencies and priorities allow, until the file is fully ingested into all necessary entity type table objects.

The project also coordinates the dissemination of data, by refreshing of data marts and products downstream of IMD, such as:

- DMI (Data Mart Individual)

- DMI_Commercial (DMI for commercial purposes)

- Movers_Mart (core data mart for Censai product)

- DMI_Historic (DMI at a point in time)

- Digital Segments

- Reference data for I360 Portal.

Data privacy request records are matched to IMD individual data, and are continuously flagged for PII suppression or deletion according to data privacy laws. Individual data obtained from voter registration files from states with commercial use prohibitions are prohibited from use in I360's commercial data environments.
