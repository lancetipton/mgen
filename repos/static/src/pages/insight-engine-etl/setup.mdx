## Description

Setup file for Insight Engine ETL Python package

This file defines the setup configuration for the Insight Engine ETL Python package. It specifies metadata like the package name, version, and author. It also defines the package dependencies that will be installed automatically when this package is installed. This allows any Python code in this package or its subpackages to import and use the specified third party libraries. The find_packages function excludes non-Python files from the package so that only actual Python modules are included. Overall this file provides the necessary configuration to distribute and install the Insight Engine ETL Python code as a reusable package.
